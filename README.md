# "What If..." Reels

Short-form 3D reels.

## Series rules

**Basketball — "What if..."**
- Imagine a scenario, then answer it only with real physics, biology or verified stats.
- Every number must have a source or show its working. Estimates are labelled as estimates.
- Stats come from Basketball-Reference / NBA.com, never from memory.

**Islamic — storytelling only (no "what if")**
- Tell real stories only: Qur'an, authentic (sahih/hasan) hadith, and established seerah.
- No exaggerating, no invented dialogue, no speculation about the unseen (ghayb).
- Put the reference on screen (e.g. *Sahih al-Bukhari 1*, *Surah Yusuf 12:4*).
- Visual rule: no faces or bodies of prophets or Sahaba. Use places, objects, silhouettes, or nature shots.
